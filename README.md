## 🎧 Концепция: «Супер крутой звук»
VST-плагин для **FL Studio**, генерирующий **супер атмосферные** звуковые ландшафты и атмосферу.

**Основа звука (Супер параметры):**
- **Шум:** гранулированный шум (уровень 0.8), имитация «радиопомех» и «ветра между домами» (Юго-Запад СПб, `southwestWind: 0.75`).
- **Басс:** глубокий, «холодный» пост-панк бас (45Hz, `brutalistTexture: 0.95`).
- **Атмосфера:** реверберация (размер 0.95, `spectralShift: 0.85`), фильтры (800Hz, бетонные стены).
- **Новые «супер» функции:**
  - **Дисторшн:** пост-панк 2000-х (уровень 0.6, брутализм).
  - **Модуляция:** ветер между домами (уровень 0.5, динамика).
  - **Гранулярность:** панельные дома (уровень 0.9, супер детализация).
  - **Темп:** пост-панк ритм (90 BPM, медленно и атмосферно).
  - **Резонанс:** холодный, бетонные стены (уровень 0.7, пронзительно).
  - **Стерео-эффект:** дворы (уровень 0.9, пространство).
  - **Эхо:** панельные дома (задержка 2.5с, `panelEchoDepth: 3.0с` — супер атмосфера).

**🚀 12 Нововведений (Innovations v1.1.1)**
1. **Юго-Западный Ветровой Гейт (SW Wind Gate)** — динамический гейт, реагирующий на «ветер» между панельками (`southwestWind`).
2. **Бруталистская Текстура 2.0 (Brutalist Texture Mapping)** — морфинг звука в «бетон» через `spectralShift` и `distortion`.
3. **Панельный Эхо-Резонанс (Panel Echo Resonance)** — синхронизация `panelEchoDepth` с `resonance` для «холодных» дворов.
4. **Пост-Панк Ритм-Синхро (Post-Punk Sync)** — автоматизация `tempo` (90 BPM) под «холодный бас» (45Hz).
5. **Стерео-Двор (Courtyard Stereo Expansion)** — расширение `stereoEffect` (0.9) с имитацией «эха панелей» в боковых каналах.
6. **Гранулярный Шум-Шторм (Granular Noise Storm)** — усиление `granularity` (0.9) для «радиопомех» и «ветра».
7. **Фильтр Бетонных Стен (Concrete Wall Filter)** — резонансный фильтр (800Hz) с «супер атмосферным» сдвигом (`spectralShift` 0.85).
8. **Модуляция Ветровой Динамики (Wind Dynamics Modulation)** — модуляция (`modulation` 0.5) частоты басса в зависимости от «ветра».
9. **Дисторшн Пост-Панка (Post-Punk Distortion Engine)** — бруталистский дисторшн (`distortion` 0.6) с «холодным» срезом.
10. **Атмосферный Реверб-Ландшафт (Atmospheric Reverb Landscape)** — реверберация (`reverbSize` 0.95) с «глубиной панелей» (`panelEchoDepth` 3.0с).
11. **Визуализация «Серое Небо» (Grey Sky GUI)** — интерфейс с «бруталистским» шрифтом и «бетонными» цветами (фото/видео/шрифты).
12. **FL Studio Пресет-Бридж (FL Studio Preset Bridge)** — прямая интеграция «супер атмосферных» пресетов в FL Studio (файл `presets/super_atmospheric_v1_1_1.json`).

## 🚀 Разработка (Прототип на Node.js / JavaScript)
Поскольку Rust/vst-rs требует сборки в среде с доступом к компилятору, мы создали **супер атмосферный прототип на Node.js / JavaScript** (v1.1.1).

### Структура прототипа
- `package.json` — конфигурация проекта.
- `src/index.js` — основной код плагина (супер атмосферная логика).
- `presets/super_atmospheric_v1_1_1.json` — пресеты для FL Studio.

### Как запустить прототип
1. Установите зависимости: `npm install`
2. Запустите прототип: `npm run dev`

### Как использовать в FL Studio (в будущем)
1. **Ручное слияние PR #3 (через opencode/ручную работу):** синхронизация «супер атмосферной» логики в Rust (`src/dsp/*.rs`) в `main` (коммит `e383419` vs `9b25f82`).
2. Соберите плагин на Rust: `cargo build --release` (Rust 1.88.0 уже установлен — см. раздел
   «🦀 Разработка на Rust»; для полной сборки нужен доступ к `crates.io`).
3. Найдите скомпилированный `.dll` (Windows) или `.vst3` (macOS/Linux) в `target/release`.
4. Добавьте плагин в FL Studio (`Options -> Plugins -> Manage plugins`).
5. Используйте «супер атмосферные» пресеты из `presets/super_atmospheric_v1_1_1.json`.

## 🦀 Разработка на Rust

### Тулчейн уже установлен
```
$ rustc --version
rustc 1.88.0 (6b00bc388 2025-06-23)
$ cargo --version
cargo 1.88.0 (873a06493 2025-05-10)
```
Компилятор установлен в `/opt/rust` (симлинки `rustc`, `cargo`, `rustdoc` в `/usr/local/bin`).

### Установка заново (в т.ч. без доступа к `static.rust-lang.org`)
```bash
./scripts/install_rust_offline.sh            # ставит rustc/cargo/rust-std в /opt/rust
RUST_PREFIX=$HOME/rust ./scripts/install_rust_offline.sh
```
Скрипт скачивает компоненты тулчейна из npm-реестра (пакеты `@rustbin/rustc-*`,
`@rustbin/cargo-*`, `@rustbin/rust-std-*`) и ставит их штатным `install.sh`.
Обычный путь (`curl https://sh.rustup.rs | sh`) тоже работает, если сеть открыта.

### Проверка DSP-ядра без внешних зависимостей
DSP-ядро не зависит от `nih-plug`/`egui`, поэтому оно собирается даже когда
`crates.io` недоступен:
```bash
cd tools/dsp_standalone
cargo test            # 5 тестов: параметры, 90 BPM, эхо 120000/144000 сэмплов, фильтр
cargo run --release   # полная цепочка: 12 инноваций + 12 улучшений
```
Пример вывода: `Cutoff: 800Hz -> 1480Hz (shift 0.85)`, `Beat: 0.666667 s`,
`Echo delay: 120000 samples`, `Panel echo depth: 144000 samples`.

### Полная сборка плагина (VST3 для FL Studio)
```bash
cargo build --release
```
Для этой команды нужен доступ к `crates.io` — зависимость `nih-plug` + `egui`
тянет ~200 крейтов. В закрытой песочнице сборка падает на
`failed to download from https://index.crates.io/config.json` — на машине с
открытым интернетом всё собирается без изменений (`target/release/post_ambient_vst.vst3`).

## 🛠️ Как добавить новые «супер» параметры (для разработчиков)
1. Откройте `src/index.js`.
2. Добавьте новый параметр в `constructor()` (например, `this.spectralShift = 0.85`).
3. Добавьте функцию обработки в `process()` (например, `this.applySpectralShift()`).
4. Обновите `renderGUI()` (красивее интерфейс).
5. Запустите `npm run dev`.
6. Сделайте коммит и пуш в ветку `arena/139069db-post-ambient-vst`.
