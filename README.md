## 🎧 Концепция: «Супер крутой звук»
VST-плагин для **FL Studio**, генерирующий **супер атмосферные** звуковые ландшафты и атмосферу.

**Основа звука (Супер параметры):**
- **Шум:** гранулированный шум (уровень 0.8), имитация «радиопомех» и «ветра между домами» (Юго-Запад СПб, `southwestWind: 0.75`).
- **Басс:** глубокий, «холодный» пост-панк бас (45Hz, `brutalistTexture: 0.95`).
- **Атмосфера:** реверберация (размер 0.95, `spectralShift: 0.85`), фильтры (800Hz, бетонные стены).
- **Новые «супер» функции:**
  - **Дисторшн:** пост-панк 2000-х (уровень 0.6, брутализм).
  - **Модуляция:** ветер между домами (уровень 0.5, динамика).
  - **Гранулярность:** панельные дома (уровень 0.9, супер детализация).
  - **Темп:** пост-панк ритм (90 BPM, медленно и атмосферно).
  - **Резонанс:** холодный, бетонные стены (уровень 0.7, пронзительно).
  - **Стерео-эффект:** дворы (уровень 0.9, пространство).
  - **Эхо:** панельные дома (задержка 2.5с, `panelEchoDepth: 3.0с` — супер атмосфера).

**Визуализация:**
- Темный дизайн, «брутализм», минимализм, шрифты в стиле плакатов 2000-х, визуализация «бетона» и «серого неба».

## 🛠️ Технологии
- **Язык:** **JavaScript/Node.js** (прототип v1.1.0), **Rust** (цель для VST3 в FL Studio).
- **Фреймворк:** `vst-rs` (Rust), `nih-plug` (аудио), `egui` (интерфейс).
- **Прототип:** Запущен в Node.js, демонстрирует **супер атмосферную** логику генерации звука.

## 🚀 Разработка (Прототип на Node.js / JavaScript)
Поскольку Rust/vst-rs требует сборки в среде с доступом к компилятору, мы создали **супер атмосферный прототип на Node.js / JavaScript**.

### Структура прототипа
- `package.json` — конфигурация проекта.
- `src/index.js` — основной код плагина (супер атмосферная логика).

### Как запустить прототип
1. Установите зависимости: `npm install`
2. Запустите прототип: `npm run dev`

### Как использовать в FL Studio (в будущем)
1. Соберите плагин на Rust: `cargo build --release` (требуется установка Rust/vst-rs).
2. Найдите скомпилированный `.dll` (Windows) или `.vst3` (macOS/Linux) в `target/release`.
3. Добавьте плагин в FL Studio (`Options -> Plugins -> Manage plugins`).
4. Используйте плагин для генерации **супер атмосферных** эмбиент-звуков и атмосферы.

## 🛠️ Как добавить новые «супер» параметры (для разработчиков)
1. Откройте `src/index.js`.
2. Добавьте новый параметр в `constructor()` (например, `this.spectralShift = 0.85`).
3. Добавьте функцию обработки в `process()` (например, `this.applySpectralShift()`).
4. Обновите `renderGUI()`.
5. Запустите `npm run dev`.
6. Сделайте коммит и пуш в ветку `arena/139069db-post-ambient-vst`.
