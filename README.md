# post_ambient_vst - VST Plugin for FL Studio

## Концепция
VST-плагин, генерирующий эмбиент-звуковые ландшафты и атмосферу в стиле **пост-панк 2000-х**.

**Основа звука:**
- **Шум:** гранулированный шум, имитация «радиопомех» и «ветра между домами» (Юго-Запад СПб).
- **Басс:** глубокий, «холодный» пост-панк бас (в духе «Кино», Molchat Doma, ранний «Сплин»).
- **Атмосфера:** реверберация (панельные дома, эхо дворов), фильтры (низкочастотные, имитирующие бетонные стены).
- **Новые функции:**
  - **Дисторшн:** пост-панк 2000-х (искажение звука, «бетонные стены»).
  - **Модуляция:** ветер между домами (изменение частоты, «радиопомехи»).
  - **Гранулярность:** панельные дома (разбиение шума на части).

**Визуализация:**
- Темный дизайн, «брутализм», минимализм, шрифты в стиле плакатов 2000-х, визуализация «бетона» и «серого неба».

## Технологии
- **Язык:** JavaScript (прототип), **Rust** (рекомендуется для финальной версии VST3 в FL Studio).
- **Фреймворк:** `vst-rs` (для Rust), `nih-plug` (аудио), `egui` (интерфейс в стиле 2000-х).
- **Прототип:** Запущен в Node.js, демонстрирует логику генерации шума, басса, атмосферы, дисторшна и модуляции.

## Структура проекта
- `package.json` — конфигурация проекта.
- `package-lock.json` — зависимости.
- `src/index.js` — основной код плагина (генерация шума, басса, атмосферы, дисторшна, модуляции).
- `README.md` — документация.

## Вдохновение
- Фотографии дома (прикреплены в чате).
- Видео с Юго-Запада СПб (ссылка в чате).
- Музыкальный стиль: пост-панк 2000-х, эмбиент, шум, басс.

## Разработка (Прототип на Node.js / JavaScript)
Поскольку Rust/vst-rs требует сборки в среде с доступом к компилятору, мы создали **прототип на Node.js / JavaScript**, который демонстрирует логику генерации звука и интерфейса.

### Структура прототипа
- `package.json` — конфигурация проекта.
- `src/index.js` — основной код плагина (генерация шума, басса, атмосферы, дисторшна, модуляции).

### Как запустить прототип
1. Установите зависимости: `npm install`
2. Запустите прототип: `npm run dev`

### Как использовать в FL Studio (в будущем)
1. Соберите плагин на Rust: `cargo build --release` (требуется установка Rust/vst-rs).
2. Найдите скомпилированный `.dll` (Windows) или `.vst3` (macOS/Linux) в `target/release`.
3. Добавьте плагин в FL Studio (Options -> Plugins -> Manage plugins).
4. Используйте плагин для генерации эмбиент-звуков и атмосферы.
